    立体几何 + 概率统计 · Cross Reading 卡片¶

    上海卷地位：图形与几何合计占约35%，其中立体几何约12分（填空+解答），概率统计约10分

    第一部分：立体几何¶

    面①：核心公式速查¶

    空间几何体的表面积与体积¶

    几何体 体积公式 表面积/侧面积
    柱体（棱柱/圆柱） V = Sh S侧 = Ch（C为底面周长）
    锥体（棱锥/圆锥） V = ⅓Sh S侧 = ½Cl（l为母线长，圆锥）
    台体（棱台/圆台） V = ⅓(S₁ + S₂ + √(S₁S₂))h —
    球 V = ⁴⁄₃πR³ S = 4πR²

    空间向量基本公式¶

    公式 表达式 用途
    向量夹角 cos θ = a·b / ( a
    线面角 sin θ = n·d
    二面角 cos θ = n₁·n₂ / ( n₁
    点到平面距离 d = n·AP

    线面平行/垂直判定¶

    关系 判定方法
    线∥面 线平行于面内一条直线
    线⊥面 线垂直于面内两条相交直线
    面∥面 一个面内两条相交直线分别平行于另一个面
    面⊥面 一个面经过另一个面的垂线

    面②：解题套路¶

    套路1：用空间向量解立体几何¶

    步骤1：建立空间直角坐标系（找三条两两垂直的线）
步骤2：写出各点坐标
步骤3：写出相关向量（方向向量、法向量）
步骤4：利用向量公式计算（夹角/距离/垂直/平行）

    ⚠️ 建系要点： - 优先选已有垂直关系的棱作为坐标轴 - 原点选在顶点或中点 - 注意z轴方向

    套路2：求法向量¶

    已知平面过三点 A, B, C
→ 向量 AB, AC
→ 设法向量 n = (x, y, z)
→ n·AB = 0 且 n·AC = 0
→ 解方程组 → 得法向量（可取一个特解）

    套路3：线面角¶

    线面角 = 直线与它在平面内的投影的夹角
sin(线面角) = |n·d| / (|n|·|d|)

    ⚠️ 易错点：线面角的范围是 [0, π/2]，sin 值非负

    套路4：二面角¶

    方法1：定义法 → 找二面角的平面角（棱上一点，在两个面内各作一条垂直于棱的直线）
方法2：法向量法 → cos θ = |n₁·n₂| / (|n₁|·|n₂|)

    ⚠️ 易错点： - 法向量夹角 ≠ 二面角（可能互补） - 需要根据图形判断取锐角还是钝角

    面③：常见模型¶

    模型 特点 常见考法
    正方体/长方体 天然建系 线面角、二面角、距离
    正棱锥 顶点投影在底面中心 高、侧棱、侧面与底面夹角
    圆柱/圆锥 旋转体 截面、展开图、最值
    球 对称性 截面圆、球内接几何体

    第二部分：概率统计¶

    面④：核心公式速查¶

    排列组合¶

    概念 公式 说明
    排列 A(n,m) = n!/(n-m)! 有序
    组合 C(n,m) = n!/[m!(n-m)!] 无序
    组合性质 C(n,m) = C(n,n-m) 对称性
    组合性质 C(n,m) + C(n,m-1) = C(n+1,m) 杨辉三角

    概率¶

    类型 公式 说明
    古典概型 P(A) = A的包含结果数 / 总结果数 等可能
    互斥事件 P(A∪B) = P(A) + P(B) A、B不同时发生
    对立事件 P(A) + P(Ā) = 1 —
    独立事件 P(AB) = P(A) · P(B) A、B互不影响
    条件概率 P(A B) = P(AB) / P(B)

    离散型随机变量¶

    分布 表达式 E(X) D(X)
    二项分布 B(n,p) P(X=k) = C(n,k)pᵏ(1-p)ⁿ⁻ᵏ np np(1-p)
    超几何分布 P(X=k) = C(M,k)C(N-M,n-k)/C(N,n) nM/N —

    正态分布¶

    X ~ N(μ, σ²) - P(μ-σ < X < μ+σ) ≈ 0.6827 - P(μ-2σ < X < μ+2σ) ≈ 0.9545 - P(μ-3σ < X < μ+3σ) ≈ 0.9973

    期望与方差¶

    性质 公式
    E(aX + b) aE(X) + b
    D(aX + b) a²D(X)
    D(X) E(X²) - [E(X)]²

    面⑤：解题套路与易错点¶

    套路1：排列组合¶

    步骤1：判断有序还是无序 → 排列 or 组合
步骤2：分类（加法原理）还是分步（乘法原理）
步骤3：特殊元素/位置优先处理

    常用方法： - 捆绑法：相邻问题 → 把相邻元素捆绑 - 插空法：不相邻问题 → 先排其他，再插入 - 排除法：正面不好算 → 总数 - 不符合的

    ⚠️ 易错点： - "至少"类问题 → 考虑对立事件 - 分类时确保不重不漏 - 平均分组要除以组数的阶乘

    套路2：概率大题¶

    步骤1：确定随机变量 X 的取值
步骤2：计算每个取值的概率
步骤3：列出分布列
步骤4：计算 E(X) 和 D(X)
步骤5：根据题意回答

    上海卷概率统计常见考法¶

    考法 题型 分值 难度
    排列组合计数 填空/选择 4~5分 ★★
    古典概型 填空 4~5分 ★★
    随机变量分布列 解答 14分 ★★★
    期望与方差 解答 14分 ★★★
    正态分布 填空/选择 4~5分 ★

    ⚠️ 考前必查易错点¶

    # 易错点 记住
    1 排列组合分不清 有序用排列，无序用组合
    2 平均分组忘记除以组数阶乘 分成k个相同的组 → 除以 k!
    3 二项分布参数看反 B(n,p) 中 n 是次数，p 是概率
    4 条件概率和独立事件混淆 P(A
    5 法向量夹角直接当二面角 要看图形判断锐钝
