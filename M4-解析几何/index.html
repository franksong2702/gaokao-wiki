    解析几何 · Cross Reading 卡片¶

    上海卷地位：解析几何占整卷约 28.7%，是第二大模块。圆锥曲线（椭圆、双曲线、抛物线）是压轴题20题的常客

    面①：核心公式速查¶

    直线¶

    形式 方程 适用场景
    点斜式 y - y₀ = k(x - x₀) 已知点和斜率
    斜截式 y = kx + b 已知斜率和截距
    一般式 Ax + By + C = 0 通用
    两点式 (y-y₁)/(y₂-y₁) = (x-x₁)/(x₂-x₁) 已知两点

    两直线关系： - 平行：k₁ = k₂（或 A₁B₂ = A₂B₁） - 垂直：k₁ · k₂ = -1（或 A₁A₂ + B₁B₂ = 0）

    点到直线距离：d = |Ax₀ + By₀ + C| / √(A² + B²)

    圆¶

    形式 方程 说明
    标准式 (x - a)² + (y - b)² = r² 圆心 (a,b)，半径 r
    一般式 x² + y² + Dx + Ey + F = 0 圆心 (-D/2, -E/2)，r = ½√(D²+E²-4F)

    直线与圆的位置关系： - d < r → 相交（2个交点） - d = r → 相切（1个交点） - d > r → 相离（无交点）

    椭圆¶

    项目 x²/a² + y²/b² = 1 (a>b>0) x²/b² + y²/a² = 1 (a>b>0)
    焦点 (±c, 0) (0, ±c)
    焦距 2c 2c
    a,b,c关系 c² = a² - b² c² = a² - b²
    长轴 2a 2a
    短轴 2b 2b
    离心率 e = c/a ∈ (0, 1) e = c/a ∈ (0, 1)
    准线 x = ±a²/c y = ±a²/c

    椭圆定义：|PF₁| + |PF₂| = 2a

    双曲线¶

    项目 x²/a² - y²/b² = 1 y²/a² - x²/b² = 1
    焦点 (±c, 0) (0, ±c)
    a,b,c关系 c² = a² + b² c² = a² + b²
    离心率 e = c/a > 1 e = c/a > 1
    渐近线 y = ±(b/a)x y = ±(a/b)x

    双曲线定义：||PF₁| - |PF₂|| = 2a

    抛物线¶

    方程 焦点 准线 对称轴
    y² = 2px (p>0) (p/2, 0) x = -p/2 x轴
    y² = -2px (-p/2, 0) x = p/2 x轴
    x² = 2py (0, p/2) y = -p/2 y轴
    x² = -2py (0, -p/2) y = p/2 y轴

    抛物线定义：|PF| = d（P到焦点距离 = P到准线距离）

    面②：解题套路¶

    套路1：直线与圆锥曲线相交（联立法）¶

    步骤1：设直线方程 y = kx + m（或 x = my + n）
步骤2：联立直线与曲线方程 → 消去一个变量 → 得到一元二次方程
步骤3：写出 Δ（判别式）→ 确保 Δ > 0（有交点）
步骤4：写出韦达定理：x₁ + x₂, x₁ · x₂
步骤5：根据题目要求（弦长、面积、角度等）列式求解

    弦长公式¶

    |AB| = √(1+k²) · |x₁ - x₂| = √(1+k²) · √[(x₁+x₂)² - 4x₁x₂]

    或（消y时）：|AB| = √(1+1/k²) · |y₁ - y₂|

    套路2：中点弦问题¶

    已知弦 AB 的中点 M(x₀, y₀)，求直线 AB 的方程

方法：点差法
设 A(x₁,y₁), B(x₂,y₂)，M(x₀,y₀) 为中点
→ x₁ + x₂ = 2x₀, y₁ + y₂ = 2y₀
→ 代入曲线方程后相减 → 得到 k = (y₁-y₂)/(x₁-x₂) 的表达式

    套路3：定点/定值问题¶

    方法1：特殊值法 → 取特殊位置猜出定点 → 再证明
方法2：设参数 → 列式化简 → 消去参数 → 得到定值

    套路4：最值/范围问题¶

    方法1：转化为函数求最值（参数法）
方法2：利用几何性质（如焦半径公式）
方法3：基本不等式
方法4：判别式法（Δ ≥ 0 确定参数范围）

    面③：重要二级结论¶

    椭圆¶

    结论 公式
    焦半径
    通径（过焦点垂直于长轴的弦） 2b²/a
    椭圆上点到焦点距离范围 [a-c, a+c]
    焦点三角形面积 S = b² · tan(θ/2)，θ = ∠F₁PF₂

    双曲线¶

    结论 公式
    焦半径
    通径 2b²/a
    焦点三角形面积 S = b² / tan(θ/2)

    抛物线¶

    结论 公式
    焦半径
    焦点弦
    通径 2p

    面④：上海卷考法统计¶

    常见题型¶

    考法 题型 分值 难度
    求椭圆/双曲线方程 填空/解答 4~14分 ★★~★★★
    离心率计算 填空 4~5分 ★★
    直线与圆锥曲线相交 解答 14~16分 ★★★★
    弦长/面积计算 解答 14~16分 ★★★★
    定点/定值/范围 压轴 16~18分 ★★★★★

    压轴题20题常见考法¶

    1. 椭圆/双曲线的标准方程 → 利用定义或已知条件
    2. 直线与曲线相交 → 韦达定理 + 弦长
    3. 三角形面积最值 → 转化为函数最值
    4. 定点问题 → 设参数 + 消参

    ⚠️ 考前必查5个易错点¶

    # 易错点 记住
    1 设直线时忽略斜率不存在的情况 分类讨论 k 存在和不存在
    2 联立后忘记写 Δ > 0 Δ > 0 是前提条件
    3 韦达定理用错符号 x₁+x₂ = -b/a, x₁·x₂ = c/a
    4 椭圆/双曲线 a,b,c 关系记混 椭圆：a² = b² + c²；双曲线：c² = a² + b²
    5 抛物线焦点坐标记错 y² = 2px → 焦点 (p/2, 0)，准线 x = -p/2

    面⑤：最后30天复习策略¶

    每天10分钟专项¶

    Day 1-2: 椭圆/双曲线标准方程 → 做3道求方程
Day 3-4: 直线与椭圆联立 → 做2道（写完整韦达定理步骤）
Day 5-6: 弦长公式应用 → 做2道
Day 7-8: 面积/最值问题 → 做2道
Day 9-10: 定点/定值问题 → 做1道

    万能解题流程（联立法）¶

    1. 设直线 → 2. 联立 → 3. 消元 → 4. 写Δ → 5. 韦达定理
→ 6. 根据题意列式 → 7. 化简 → 8. 求解 → 9. 检验

    关键：这个流程要练到肌肉记忆。考试中哪怕算到最后，前面的步骤分也能拿不少。
