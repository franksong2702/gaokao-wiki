    数列 · Cross Reading 卡片¶

    上海卷地位：数列是压轴题的"老搭档"之一（2018-2020年20、21题常客），常与函数、不等式、解析几何结合考查

    面①：核心公式速查¶

    等差数列¶

    公式 表达式 说明
    通项 aₙ = a₁ + (n-1)d 知三求一
    前n项和 Sₙ = n(a₁ + aₙ)/2 首末项法
    前n项和 Sₙ = na₁ + n(n-1)d/2 知首项和公差
    等差中项 2b = a + c b 是 a、c 的等差中项

    性质： - aₙ = aₘ + (n-m)d - 若 m+n = p+q，则 aₘ + aₙ = aₚ + aₑ - Sₙ, S₂ₙ - Sₙ, S₃ₙ - S₂ₙ 成等差

    等比数列¶

    公式 表达式 说明
    通项 aₙ = a₁ · qⁿ⁻¹ 知三求一
    前n项和 Sₙ = a₁(1-qⁿ)/(1-q) q ≠ 1 时
    前n项和 Sₙ = na₁ q = 1 时（千万别漏！）
    等比中项 b² = ac b 是 a、c 的等比中项（注意符号）

    性质： - aₙ = aₘ · qⁿ⁻ᵐ - 若 m+n = p+q，则 aₘ · aₙ = aₚ · aₑ

    面②：解题套路¶

    套路1：求通项公式¶

    已知条件 方法 步骤
    aₙ₊₁ = aₙ + f(n) 累加法 aₙ = a₁ + Σf(k)
    aₙ₊₁ = f(n) · aₙ 累乘法 aₙ = a₁ · Πf(k)
    aₙ₊₁ = paₙ + q (p≠1) 构造法 令 aₙ₊₁ + λ = p(aₙ + λ)，求 λ = q/(p-1)
    aₙ₊₁ = paₙ + qⁿ 同除法 两边除以 qⁿ⁺¹
    Sₙ = f(aₙ) Sₙ 法 aₙ = Sₙ - Sₙ₋₁ (n ≥ 2)，验证 n=1

    ⚠️ 易错点： - aₙ = Sₙ - Sₙ₋₁ 只在 n ≥ 2 时成立，n = 1 要单独验证！ - 构造法中等比数列的首项是新数列的首项，不是原数列的

    套路2：求前n项和¶

    方法 适用场景 操作
    公式法 等差/等比 直接套公式
    裂项相消法 aₙ = 1/[n(n+1)] 型 拆成 1/n - 1/(n+1)，相邻项抵消
    错位相减法 aₙ = n · qⁿ 型（等差×等比） ①写 Sₙ ②两边乘 q ③相减
    分组求和法 奇偶项不同规律 分开求和后合并
    倒序相加法 对称性求和 正序 + 倒序

    错位相减法（详解）¶

    求 Sₙ = 1·2 + 2·2² + 3·2³ + ... + n·2ⁿ

步骤1：写出 Sₙ
Sₙ = 1·2 + 2·2² + 3·2³ + ... + n·2ⁿ     ... ①

步骤2：两边乘公比 q = 2
2Sₙ = 1·2² + 2·2³ + ... + (n-1)·2ⁿ + n·2ⁿ⁺¹  ... ②

步骤3：① - ②
-Sₙ = 2 + 2² + 2³ + ... + 2ⁿ - n·2ⁿ⁺¹
     = 2(2ⁿ - 1)/(2 - 1) - n·2ⁿ⁺¹
     = 2ⁿ⁺¹ - 2 - n·2ⁿ⁺¹

步骤4：整理
Sₙ = (n - 1)·2ⁿ⁺¹ + 2

    ⚠️ 易错点： - 最后一项 n·2ⁿ⁺¹ 的符号容易出错 - 中间等比求和项数要数对

    套路3：数列不等式证明¶

    目标：证明 Σaₖ < M 或 Σaₖ > M

方法1：放缩法 → aₙ < bₙ → Σaₙ < Σbₙ（bₙ可求和）
方法2：数学归纳法 → 验证 n=1 → 假设 n=k 成立 → 证明 n=k+1
方法3：单调性 → 证明 Sₙ 单调递增/有上界

    面③：常用裂项公式¶

    通项 裂项结果
    1/[n(n+1)] 1/n - 1/(n+1)
    1/[n(n+2)] ½(1/n - 1/(n+2))
    1/[(2n-1)(2n+1)] ½(1/(2n-1) - 1/(2n+1))
    1/[√n + √(n+1)] √(n+1) - √n
    1/[n(n+1)(n+2)] ½[1/(n(n+1)) - 1/((n+1)(n+2))]

    面④：上海卷考法统计¶

    常见题型¶

    考法 题型 分值 难度
    求等差/等比通项 填空 4分 ★
    求前n项和 填空/解答 4~14分 ★★~★★★
    已知 Sₙ 求 aₙ 填空/选择 4~5分 ★★
    构造新数列 填空/解答 5~14分 ★★★
    数列不等式证明 压轴 16~18分 ★★★★★
    数列与函数综合 压轴 16~18分 ★★★★★

    压轴题高频考法¶

    1. 递推关系求通项 → 构造等比数列
    2. 数列不等式 → 放缩法 + 裂项相消
    3. 数列与函数 → aₙ = f(n)，利用函数性质
    4. 数列与新定义 → 创新题型（近年趋势）

    ⚠️ 考前必查5个易错点¶

    # 易错点 记住
    1 等比求和忘记讨论 q = 1 先判 q = 1
    2 aₙ = Sₙ - Sₙ₋₁ 用在 n = 1 n ≥ 2！n = 1 单独算
    3 裂项相消漏掉首尾项 写出前3项和后3项再消
    4 错位相减法最后一项符号错 仔细对齐，逐项相减
    5 数学归纳法第二步没用归纳假设 必须用到假设！

    面⑤：最后30天复习策略¶

    每天10分钟专项¶

    Day 1-2: 等差/等比基本公式 → 做5道通项+求和
Day 3-4: 递推求通项（累加/累乘/构造）→ 做4道
Day 5-6: 裂项相消法 → 做4道求和
Day 7-8: 错位相减法 → 做3道（写完整步骤）
Day 9-10: 数列不等式 → 做2道放缩 + 1道归纳

    二级结论（提速用）¶

    结论 说明
    S₂ₙ₋₁ = (2n-1)·aₙ 等差数列奇数项和
    若 {aₙ} 等差，则 {Sₙ/n} 等差 平均值成等差
    若 {aₙ} 等比，则 {Sₙ} 一般不等比 除非 q = 1
    aₙ = Sₙ - Sₙ₋₁ (n ≥ 2) 万能通项公式
