    三角函数 · Cross Reading 卡片¶

    上海卷占比：约15分（填空/选择+可能出现在解答题中）

    面①：核心公式速查¶

    同角关系¶

    公式 用途
    sin²α + cos²α = 1 知一求二
    tan α = sin α / cos α 弦切互化
    1 + tan²α = 1/cos²α 切弦互化

    诱导公式（奇变偶不变，符号看象限）¶

    公式 说明
    sin(π/2 - α) = cos α 奇变
    sin(π/2 + α) = cos α 奇变
    sin(π - α) = sin α 偶不变
    sin(π + α) = -sin α 偶不变
    sin(2π - α) = -sin α 偶不变
    cos(π/2 - α) = sin α 奇变
    cos(π - α) = -cos α 偶不变

    口诀："奇变偶不变，符号看象限" - 奇偶指的是 kπ/2 中 k 的奇偶 - 符号看 α 为锐角时原函数在该象限的符号

    和差角公式¶

    公式 记忆提示
    sin(α ± β) = sin α cos β ± cos α sin β 同号
    cos(α ± β) = cos α cos β ∓ sin α sin β 异号（注意！）
    tan(α ± β) = (tan α ± tan β) / (1 ∓ tan α tan β) 同号

    二倍角公式¶

    公式 变形式
    sin 2α = 2 sin α cos α sin α cos α = sin 2α / 2
    cos 2α = cos²α - sin²α 最常用
    cos 2α = 2cos²α - 1 cos²α = (1 + cos 2α)/2 降幂公式
    cos 2α = 1 - 2sin²α sin²α = (1 - cos 2α)/2 降幂公式
    tan 2α = 2tan α / (1 - tan²α) —

    辅助角公式¶

    a sin x + b cos x = √(a² + b²) sin(x + φ)

    其中 tan φ = b/a，φ 所在象限由 (a, b) 决定。

    用途：将 asinx + bcosx 化为单一三角函数，求最值/周期/单调区间

    面②：解题套路¶

    套路1：化简求值¶

    给三角函数式 → 用诱导公式统一角 → 用和差/二倍角公式化简 → 代入求值

    ⚠️ 易错点： - 化简前先确定角的范围，避免符号错误 - 注意 cos(α-β) 和 cos(α+β) 的符号差异

    套路2：求 y = A sin(ωx + φ) 的性质¶

    给 f(x) = A sin(ωx + φ) + B
→ 周期 T = 2π/|ω|
→ 振幅 = |A|
→ 最大值 = A + B，最小值 = -A + B
→ 单调区间：整体代换，"脱衣法"

    单调区间求法（脱衣法）： - 递增：令 2kπ - π/2 ≤ ωx + φ ≤ 2kπ + π/2 - 递减：令 2kπ + π/2 ≤ ωx + φ ≤ 2kπ + 3π/2

    ⚠️ 易错点：ω < 0 时先变号！

    套路3：解三角形¶

    已知条件 → 选定理 → 求解
两边一角 → 余弦定理
两角一边 → 正弦定理
两边两角 → 正弦或余弦

    正弦定理¶

    a/sin A = b/sin B = c/sin C = 2R（R 为外接圆半径）

    用途： - 已知两角一边 → 求其他边 - 已知两边一角 → 求其他角 - 边角互化

    余弦定理¶

    a² = b² + c² - 2bc cos A cos A = (b² + c² - a²) / 2bc

    用途： - 已知三边 → 求角 - 已知两边及夹角 → 求第三边

    ⚠️ 易错点： - 已知两边及一边对角（SSA），可能有两解、一解或无解！ - 三角形中 A + B + C = π，sin C = sin(A + B)

    面③：图像与性质¶

    y = sin x, y = cos x, y = tan x 对比¶

    性质 y = sin x y = cos x y = tan x
    定义域 R R x ≠ π/2 + kπ
    值域 [-1, 1] [-1, 1] R
    周期 2π 2π π
    奇偶性 奇函数 偶函数 奇函数
    对称中心 (kπ, 0) (π/2 + kπ, 0) (kπ/2, 0)
    对称轴 x = π/2 + kπ x = kπ 无
    递增区间 [2kπ-π/2, 2kπ+π/2] [2kπ-π, 2kπ] (kπ-π/2, kπ+π/2)

    图像变换口诀¶

    左加右减，上加下减（针对 x 和整个函数值） y = sin(x + π/3)：向左平移 π/3 y = sin(x - π/3)：向右平移 π/3 y = sin 2x：横坐标压缩为原来的 1/2 y = 2sin x：纵坐标拉伸为原来的 2 倍

    常见题型¶

    考法 题型 分值 难度
    诱导公式化简求值 填空 4~5分 ★★
    二倍角/辅助角公式化简 填空/选择 4~5分 ★★

    y = A sin(ωx+φ) 的单调区间 填空/解答 5~14分 ★★★
    正弦/余弦定理解三角形 填空/解答 5~14分 ★★★

    ⚠️ 考前必查5个易错点¶

    # 易错点 记住
    1 诱导公式符号判断错误 把α看作锐角，判断原函数象限符号
    2 cos(α+β) 和 cos(α-β) 符号搞反 cos(α±β) 是异号
    3 ω < 0 时求单调区间 先提取负号！
    4 SSA解三角形忽略多解 画图判断解的个数
    5 辅助角公式中 φ 的象限 由 (a, b) 的正负共同决定

    二级结论（提速用）¶

    结论 说明
    sin α + cos α ∈ [-√2, √2] 辅助角 a=b=1 的情况
    在△ABC 中，sin A > sin B ⟺ A > B 大边对大角
    S = ½ab sin C = ½bc sin A = ½ac sin B 三角形面积公式
    sin A + sin B + sin C ≤ 3√3/2 等号当 A=B=C=π/3 时取到
