    语法核心考点 · Cross Reading Card¶

    上海卷语法考查分布：选择题16-25题（语法填空）+ 翻译题句型 + 写作中的语法运用

    面①：时态速查（16种时态中最常考的8种）¶

    时态 结构 标志词 例句
    一般现在时 do/does always, usually, often, every ... She goes to school every day.
    一般过去时 did yesterday, last ..., ... ago, in 2020 He finished the work yesterday.
    一般将来时 will do / be going to do tomorrow, next ..., soon I will visit my grandparents tomorrow.
    现在进行时 am/is/are + doing now, at present, right now They are playing football now.
    过去进行时 was/were + doing at that time, when ... I was reading when the phone rang.
    现在完成时 have/has + done already, yet, ever, never, since, for She has lived here since 2010.
    过去完成时 had + done by the time, before, after (过去之前) He had left before I arrived.
    将来进行时 will be + doing at this time tomorrow I will be taking the exam at 9 tomorrow.

    时态判定口诀¶

    看时间标志词 → 定基本时态
看主从句关系 → 定时态呼应
看语态需求 → 定主动/被动

    时态呼应（宾语从句）¶

    主句时态 从句时态 说明
    现在时 从句可用任何时态 I think he will come.
    过去时 从句用过去范畴时态 I thought he would come.
    过去时 客观真理用一般现在时 He said the earth goes around the sun.

    面②：被动语态¶

    构成¶

    时态 结构 例句
    一般现在 am/is/are + done English is spoken worldwide.
    一般过去 was/were + done The bridge was built last year.
    现在完成 have/has been + done The work has been finished.
    情态动词 can/must/should + be + done The problem must be solved.
    进行时 am/is/are/was/were + being + done The road is being repaired.

    主动变被动口诀¶

    宾变主，主变宾（by），动词变为 be + 过去分词

    特殊被动¶

    情况 注意
    不及物动词不能被动 happen, occur, exist, belong to
    感官动词 see sb. do → sb. is seen to do
    make/let/have make sb. do → sb. is made to do
    双宾语 give sb. sth. → sb. is given sth. / sth. is given to sb.

    面③：非谓语动词（重点难点）¶

    三大形式对比¶

    形式 主动 被动 进行 完成
    不定式 to do to do to be done to be doing to have done
    动名词 doing doing being done — having done
    分词 doing done — having done

    不定式 vs 动名词（高频考点）¶

    只能 + doing 只能 + to do 两者皆可（意义不同）
    enjoy / finish want / hope / decide remember（做过 vs 要去做）
    practice / avoid promise / refuse / plan forget（做过 vs 要去做）
    mind / suggest offer / manage stop（停止做 vs 停下来去做）
    keep / consider afford / deserve regret（做过 vs 遗憾地要）
    admit / deny agree / expect try（尝试做 vs 努力去做）
    can't help pretend / threaten go on（继续做同一件事 vs 接着做另一件事）

    分词作状语¶

    类型 说明 例句
    现在分词 doing 与主语是主动关系 Walking in the park, I met a friend.
    过去分词 done 与主语是被动关系 Given more time, I could do it better.
    完成式 having done 发生在主句动作之前 Having finished the work, he went home.

    ⚠️ 易错点：分词的逻辑主语 = 句子的主语

    面④：三大从句速查¶

    定语从句¶

    关系词 先行词 在从句中充当 例句
    who 人 主语 The man who is standing there is my teacher.
    whom 人 宾语 The girl whom I met yesterday is kind.
    which 物 主语/宾语 The book which I bought is interesting.
    that 人/物 主语/宾语 The car that he drives is new.
    whose 人/物 定语 The boy whose father is a doctor ...
    where 地点 状语 This is the house where I was born.
    when 时间 状语 I'll never forget the day when we met.
    why reason 状语 That is the reason why I left.

    只用 that 的情况： - 先行词被 the only, the very, the last 修饰 - 先行词被序数词或最高级修饰 - 先行词既有人又有物 - 先行词是不定代词（all, nothing, something, anything, everything）

    非限制性定语从句： - 用 which（不能用 that） - 前面有逗号 - 修饰整句话时只能用 which

    名词性从句¶

    从句类型 引导词 例句
    主语从句 What / That / Whether What he said is true.
    宾语从句 that / if / whether / wh- I believe that he is right.
    表语从句 that / what / whether The truth is that he lied.
    同位语从句 that The fact that he won surprised everyone.

    状语从句¶

    类型 引导词
    时间 when / while / as / before / after / since / until / as soon as
    地点 where / wherever
    原因 because / since / as / now that
    目的 so that / in order that
    结果 so ... that / such ... that
    条件 if / unless / as long as / provided that
    让步 although / though / even if / even though / while
    方式 as / as if / as though
    比较 than / as ... as

    面⑤：虚拟语气¶

    if 条件句的虚拟¶

    时间 if 从句 主句
    与现在相反 过去式（be→were） would/should/could/might + do
    与过去相反 had + done would/should/could/might + have done
    与将来相反 should do / were to do / 过去式 would/should/could/might + do

    例句： - If I were you, I would accept the offer.（与现在相反） - If he had studied harder, he would have passed the exam.（与过去相反）

    特殊虚拟¶

    情况 结构 例句
    wish wish + 过去式（现在）/ had done（过去） I wish I were taller.
    suggest/order/demand 后的宾语从句 (should) + do He suggested that we (should) leave early.
    It is necessary/important that (should) + do It is important that he (should) be on time.
    would rather would rather + 过去式（现在）/ had done（过去） I'd rather you came tomorrow.

    高频易错点¶

    # 易错点 正确写法
    1 现在完成时 + 具体过去时间 ❌ I have seen him yesterday. → ✅ I saw him yesterday.
    2 since 后接从句用过去时 I have known him since we were children.
    3 so ... that vs such ... that so + adj./adv.；such + n.
    4 非限制性定语从句用 which The house, which was built in 1900, is old.
    5 定语从句中 where vs which the house where I live ≠ the house which I bought
    6 suggest 后从句用 (should) do He suggested that she (should) go.（不用 goes/went）
    7 感官动词 + doing vs do see sb. doing（正在做）vs see sb. do（做了全过程）
    8 独立主格结构 Weather permitting, we'll go.（不是 permit）
